# MenuMetrics-AI

MenuMetrics-AI is a Business Intelligence dashboard for restaurant dynamic pricing.

This tool helps restaurant owners simulate the impact of ingredient inflation on their profit margins, allowing them to adjust pricing dynamically to maintain target margins.

## Technologies Used
* **Streamlit**: For building the interactive web application.
* **Pandas**: For data manipulation and calculations.
* **Plotly**: For data visualization.
* **Scikit-Learn**: For future ML integration.

## How to Run
1. Create a virtual environment: `python -m venv venv`
2. Activate the virtual environment: `.\venv\Scripts\activate` (Windows)
3. Install requirements: `pip install -r requirements.txt`
4. Run the application: `streamlit run app.py`
